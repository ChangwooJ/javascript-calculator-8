# javascript-calculator-precourse

## 우아한 테크코스 1주차 프리코스

## 구현 기능 목록

### 입력

1. 문자열을 입력받기 위해 안내 문구를 출력한다.
   - “덧셈할 문자열을 입력해 주세요.”
2. 빈 문자열(””)이 입력될 경우 곧바로 결과값 0이 출력된다.
   - 결과 : 0

### 구분자 가능 조건

1. 커스텀 구분자 예외 처리
   - 숫자는 구분자가 될 수 없다.

### 커스텀 구분자

1. 입력된 문자열이 `//`로 시작한다면 `\n`전까지의 문자열을 커스텀 구분자로 인식한다.
   - ‘//’와 ‘\n’사이의 문자열을 한 묶음의 구분자로 처리한다.
2. 인식된 구분자는 구분자 조건(기본 조건: `,`, `:`)에 추가한다.
3. 구분자 처리가 끝난 문자열을 반환한다.

### 구분자 처리

1. 반환된 문자열을 구분자 조건을 통해 분리한다.
   - 정규식을 통해 구분자를 제외한 문자열로 분리한다.
   - 한 단어가 아닌 구분자에 대한 처리 방식을 정의한다.
   - 분리 과정에서 공백은 제거한다.

### 합산

1. 구분자 처리가 완료된 배열을 숫자로 치환한다.
   - 만약 치환된 배열이 숫자가 아니라면 "[ERROR]"로 시작하는 메시지와 함께 `Error`를 발생시킨 후 종료된다.
2. 숫자로 치환된 배열을 모두 합산해 결과값으로 반환한다.
   - 결과 : 6
